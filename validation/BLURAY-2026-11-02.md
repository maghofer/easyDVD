# Experimental Blu-ray validation

Validated on Windows x64 on 2026-11-02. Generated sources, intermediate media,
builds, queue databases and ISOs used isolated scratch storage with process-local
TEMP/TMP. The user's GUI queue, preferences and read-only Exchange originals
were not used or changed. This is software validation, not player certification.

## Authoring feasibility gate

Pinned bdmvkit 0.7.0 and udfkit 0.1.0 ran under embedded CPython 3.14.0.
Guarded source patches add per-clip video format/aspect, native SD, exact 24 fps,
mono audio signaling and explicit menu color signaling. Original licenses,
modification notices, source archives and the patch recipe accompany the runtime
or corresponding-source bundle.

An independently compiled libbluray 1.5.0 reader opened both a BDMV directory
and its UDF 2.50 ISO. It confirmed these four source titles on the same disc:

| Title | Format | Audio | Reported duration |
|---|---|---|---:|
| 1 | 720×576, 50i, 4:3 | Stereo AC-3 | 2.000 s |
| 2 | 1280×720, 50p | 5.1 AC-3 | 2.000 s |
| 3 | 1920×1080, exact 24p | Stereo AC-3 | 2.000 s |
| 4 | 1920×1080, true 59.94i | Stereo AC-3 | 2.002 s |

The reader exercised two menu pages, title selection and return, next-page
navigation, Play All through a four-clip non-seamless playlist, and automatic
playback through all titles followed by stopping. Seeking into each title
returned media for both the folder and ISO.

The menu ISO was 8,392,704 bytes. A separate 4,303,360,000-byte ISO included a
single file larger than 4 GiB; libbluray's independent UDF path sought to and
verified a marker beyond the 4 GiB boundary. Reader packages and hashes are in
`bluray-reader.lock.json`; `prepare-bluray-reader.ps1` reproduces the checker.

## Engine and media checks

- A verified I/P H.264 input was copied; Annex-B-normalized AVC SHA-256 matched
  before and after muxing. Compatible 5.1 AC-3 was copied independently.
- Missing HRD, excessive GOP duration and B-picture inputs selected encoding.
  Metadata-only High@4.1 claims did not authorize copying.
- Native PAL/NTSC SD, 720p50, exact 24p, 23.976p and true interlaced inputs
  completed preparation and full decoding.
- 1080p50 and 1080p59.94 became interlaced media. Field-rate decoding produced
  100 and 120 motion samples for the respective two-second fixtures.
- AAC surround became 5.1 AC-3; silent inputs received stereo audio. ProRes
  10-bit video with short mono PCM audio became AVC/mono AC-3, and the independent
  reader confirmed mono signaling. VFR with short audio was normalized/padded.
  SDR BT.2020 input exercised gamut conversion; HDR input was rejected.
- Long filenames containing spaces and accented characters were processed.
- A mixed-source engine queue paused after completed preparation, reopened its
  isolated SQLite state, and reused the saved media without changing its file
  modification time. It published the expected Blu-ray ISO set.
- Cancellation at the ISO stage stopped the authoring helper. Retrying the same
  private generation directory succeeded and kept prepared media valid.
- Packing tests cover BD-25/BD-50 reserves, whole-title allocation and oversized
  titles. Checkpoint tests cover profiles, stream decisions and menu/capacity
  changes. Legacy DVD media keys and serialized generation inputs remain stable.

## Regression and distribution checks

`go test ./...`, `go vet ./...` and whitespace checks passed. Race tests passed
for media, engine, subprocess handling, menus, model and packing. The complete
real-tool integration suite passed with both new Blu-ray tests and the existing
DVD tests, including Balanced/Quality PAL/NTSC, 36/99-title authoring, autoplay,
border handling, HCEnc muxing and recovery.

Headless GUI tests covered format/capacity/profile switching and saved defaults.
The Blu-ray job-settings capture was inspected; format changes resize the dialog
so the experimental-status text and controls do not overlap.

A local Windows portable package and corresponding-source ZIP were built as
`0.1.1-bluray.1`. With PATH limited to Windows system directories, the packaged
CLI found its embedded Python authoring runtime and completed a four-title
BD-50 job using an explicit external FFmpeg directory and isolated queue state.
System Python and Java were not available to that run.

The final packaged Quality profile also completed a BD-25 job with widescreen
thumbnail menus under the same restricted PATH, with HCEnc explicitly absent.
Extracted thumbnails were 640×480. The independent reader confirmed the mixed
formats, selected title two and observed its return to the menu. The generated
1920×1080 thumbnail menu artwork was inspected.

The initial source audit rejected pre-existing workstation paths
in `HCENC-MUX-2026-11-02.md` and `PERFORMANCE-2026-11-02.md`. Those files were
preserved. Packaging used an isolated source export excluding these two local
notes; its source audit passed. No release was published or installer executed
in that validation run. For release preparation, these notes and the header UI
record were deidentified; the complete repository source audit now passes.

## Remaining limits

Standalone players, actual BD-R/BD-RE media and dual-layer hardware behavior
remain unverified. Support is labeled experimental. Passthrough verifier v1
accepts a conservative progressive I/P subset; valid B-picture or interlaced
Blu-ray AVC still selects encoding when compatibility is outside that subset.
